# Changelog

All notable public changes to Craxii will be documented in this file.

## Unreleased

### Added

- Pre-alpha Rust backend with validated configuration, durable SQLite state, journal-driven projection, recovery, and health endpoints.
- Authenticated protocol-v1 bootstrap, idempotent message and cancellation commands, durable WebSocket replay, live events, and ephemeral assistant drafts.
- Scheduler and bounded agent runtime with model-provider, context-assembly, and explicit workstation-tool boundaries.
- OpenAI Responses API adapter and deterministic provider-backed tests.
- Local workstation file-read and foreground shell execution with bounded output, timeout, artifact, cancellation, and recovery semantics.
- Native macOS diagnostic client with Keychain credentials, canonical projection, reconnect/replay, message submission, and cancellation.

No versioned public release has been made.
